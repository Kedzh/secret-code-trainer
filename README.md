# 🌟 Английский, 2 класс — Игровая контрольная «Секретный код»

Интерактивный тренажёр-конструктор по картинке «Игровая контрольная “Секретный код”».
Работает в браузере на компьютере, планшете и телефоне. Открывается по ссылке:

**▶ Открыть тренажёр:** https://kedzh.github.io/secret-code-trainer/

## Что внутри

| Задание | Название | Как играть |
|---|---|---|
| 1 🔍 | «Найди пару» | Клик по заглавной букве, затем по строчной — верные пары соединяются линией |
| 2 🚂 | «Почини алфавитный поезд» | Вписать пропущенную букву (C, F, J, K, O) — буква проверяется сразу |
| 3 🕵️ | «Буквенный детектив» | Выбрать первую букву английского слова по картинке |

За каждое выполненное задание — ⭐ звезда. Все три задания открывают **секретный код SECRET** 🎉

### Бонусы
- 🔊 Звуковые сигналы и озвучка букв по-английски (кнопка «Звук»)
- ✅ «Проверить» — показать, сколько заданий выполнено
- 🔄 «Начать заново» — полный сброс для следующего ученика

## 📊 Передача результатов в Google Таблицу

1. Создайте новую [Google Таблицу](https://sheets.google.com) и назовите её (например, «Результаты — Секретный код»).
2. **Расширения → Apps Script**.
3. Удалите содержимое редактора и вставьте код из файла **[Code.gs](Code.gs)** целиком → Сохранить.
4. **Развернуть → Новое развертывание**:
   - Тип: **Веб-приложение**
   - Выполнять от имени: **Я**
   - Доступ: **Все**
5. Скопируйте «URL веб-приложения» (вида `https://script.google.com/macros/s/AKfycb.../exec`).
6. В файле `index.html` вставьте этот адрес в переменную:
   ```js
   var GOOGLE_SHEET_URL = "https://script.google.com/macros/s/AKfycb.../exec";
   ```
7. Сохраните, обновите страницу тренажёра — появится кнопка **«📩 Отправить результат»**. Результат также отправляется автоматически при открытии секретного кода.

### Что попадает в таблицу

Дата и время · имя ученика · класс · статус каждого задания · заданий выполнено (из 3) · количество ошибок · время решения · открытый код.

## 🖨 Печать классической версии

Страница стилизована под рабочий лист — её можно распечатать (Ctrl+P) без интерактива, либо использовать оригинальный PDF/картинку из задания.

## Технологии

Чистый HTML + CSS + JavaScript. Без сборки, без зависимостей, работает офлайн (кроме отправки результатов). Отправка идёт через `fetch` в режиме `no-cors` — это официально поддерживаемый способ обращения к Google Apps Script.
